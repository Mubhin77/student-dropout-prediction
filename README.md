
# Dataset Documentation

## Dataset Name
Open University Learning Analytics Dataset (OULAD)

## Source
The Open University, United Kingdom.

Official dataset:
https://www.kaggle.com/datasets/anlgrbz/student-demographics-online-education-dataoulad/data


## Dataset Description
The dataset contains student information, course registrations,
assessment records and Virtual Learning Environment (VLE) activity.

It contains 32,593 student-course registrations across
22 course presentations and seven course modules.

## Download Information

Download source: Official OULAD website

Download date: TO BE COMPLETED AFTER DOWNLOAD

Original file format: CSV

Local storage: data/raw/

## Data Files

The original dataset contains seven main CSV files:

1. studentInfo.csv
2. studentRegistration.csv
3. studentAssessment.csv
4. studentVle.csv
5. courses.csv
6. assessments.csv
7. vle.csv

## Intended Use

The dataset will be used to investigate whether early student
engagement patterns can help predict future course withdrawal.

The prediction point is the end of day 28.

## Data Integrity

The original downloaded data will remain unchanged.

An MD5 checksum will be recorded after downloading.

Processed data will be stored separately in data/processed/.

## Privacy

The dataset is anonymised. No attempt will be made to identify
individual students.
